        Sync
        
    
  
        
  
        Songs are stored as songs.json in the GitHub repo . With a token saved here, every change you make in this page is committed to the repo and the site redeploys. Without one, this device only reads the setlist and keeps its own changes locally.
        
  
        Create a fine-grained token at github.com → Settings → Developer settings → Fine-grained tokens, limited to that one repository with Contents: Read and write. Paste it once per device.
        
  
  
        
    
    
    
    
  
        
  
        
  
        
  
        Import from Ultimate Guitar
        
  
        One tap on any Ultimate Guitar or tab4u chord page sends the song here, in the right format, with title, artist, key and capo filled in. It runs in your own browser, so it works with your subscription and Pro tabs. Set it up once per device:
        
  
        ★ Send to Stage Sheets
        
  
        Laptop: drag that button onto your bookmarks bar. On a UG song page, click it.
        
  Tablet (Chrome): tap Copy below, bookmark any page (★ in the menu), then edit that bookmark: name it send and replace its address with what you copied. On a UG song page in Chrome (the website, not the UG app), tap the address bar, type send, tap the bookmark.
