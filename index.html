    Sync
    
    
  
    
  
    Songs are stored as songs.json in the GitHub repo . With a token saved here, every change you make in this page is committed to the repo and the site redeploys. Without one, this device only reads the setlist and keeps its own changes locally.
    
  
    Create a fine-grained token at github.com → Settings → Developer settings → Fine-grained tokens, limited to that one repository with Contents: Read and write. Paste it once per device.
